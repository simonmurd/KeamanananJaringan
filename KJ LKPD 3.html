2 Ringkasan Teori: Keamanan OSI Layer 2 & Mitigasi Serangan LAN

IEEE 802.1Q & Cisco Port Security

Lapisan Data Link (OSI Layer 2) sering kali menjadi titik lemah jaringan lokal karena asumsi bawaan bahwa seluruh perangkat terhubung adalah entitas terpercaya. Tanpa konfigurasi keamanan yang memadai, penyerang dapat mengeksploitasi tabel CAM, membuat server DHCP palsu, atau memalsukan identitas MAC Address.

Vektor Serangan Layer 2 & Mekanisme Mitigasinya
Vektor Serangan Dampak & Cara Kerja Serangan Teknologi Mitigasi Standard
MAC Address Spoofing Penyerang menirukan MAC Address korban untuk membajak trafik data atau memicu MAC Flapping di Switch. Port Security (Static / Sticky MAC)
Inter-VLAN Hopping Penyerang melompati batas VLAN untuk mengakses data divisi sensitif tanpa melewati Router. 802.1Q VLAN Tagging & Disable DTP Auto-Trunking
Rogue DHCP Server (MitM) Server palsu memberikan IP & Gateway milik penyerang sehingga seluruh trafik melewati peretas. DHCP Snooping (Trusted vs Untrusted Port)
ARP Cache Poisoning Manipulasi tabel ARP Client untuk mengarahkan trafik IP ke MAC penyerang. Dynamic ARP Inspection (DAI)

Mode Pelanggaran Port Security (Violation Mode)

1. Shutdown: Port mati seketika (err-disable) & butuh reset admin.
2. Restrict: Paket asing dibuang, mencatat log Syslog & menambah Violation Counter.
3. Protect: Paket asing dibuang diam-diam tanpa pencatatan counter/log.

Kapasitas Entri Tabel CAM Switch

$$\text{Kapasitas CAM} = \sum_{i=1}^{N} \text{MAC}_{\text{Port } i} \le \text{Limit Maksimum Hardware}$$ Jika kuota CAM terlampaui (MAC Flooding), Switch berubah perilaku menjadi Hub (Fail-Open Mode).

Layer 2 Access Control

Simulasi 11: MAC Spoofing & Port Mirroring

SPAN / Packet Sniffing

Lakukan pemalsuan MAC Address, amati MAC Flapping, lalu deteksi serangan menggunakan Port Mirroring (Wireshark).

PC Legal (Port 1) MAC: AA:BB:CC:11 CONNECTED
Switch Central CAM Normal
Attacker (Port 2) MAC: FF:EE:DD:99 UNTRESTED
WIRESHARK SNIFFER (PORT 8 - MONITOR) SPAN INACTIVE
[INFO] Waiting for Port Mirroring activation on Port 8...
Deteksi konflik MAC dengan Port Mirroring.

Simulasi 12: Mitigasi DHCP Rogue (DHCP Snooping)

DHCP Protection

Bandingkan distibusi IP oleh Rogue DHCP Server sebelum dan sesudah mengaktifkan DHCP Snooping Trusted Ports.

DHCP Resmi (Port 1) GW: 192.168.1.1 UNTRUSTED
Switch Central Snooping: OFF
DHCP Rogue (Port 3) GW: 192.168.1.254 UNTRUSTED
HASIL PENETAPAN IP CLIENT: MITM VULNERABLE

Client IP Address : ---.---.---.---

Assigned Gateway : ---.---.---.---

Lease Status : Unassigned

Uji blokir paket DHCP Offer ilegal.
