2 Ringkasan Teori: Pemrosesan Paket, Status Koneksi & NAT

Packet Flow Architecture

Firewall bertindak sebagai sistem pertahanan jaringan yang memeriksa paket data berdasarkan aturan (rules), status hubungan koneksi (Connection State), serta translasi alamat (NAT). Pemahaman rantai (chain) yang tepat mencegah miskonfigurasi fatal pada router[cite: 1].

Ringkasan Firewall Chains & Fitur Utama
Komponen / Chain Arah & Alur Pemrosesan Paket Data Contoh Kasus Penggunaan Utama
Chain INPUT Paket dari luar menuju langsung ke OS Router lokal[cite: 1]. Membatasi akses SSH/Winbox/Ping ke IP Gateway Router[cite: 1].
Chain OUTPUT Paket yang diinisiasi oleh OS Router lokal menuju jaringan luar[cite: 1]. NTP Client, DNS Request Router, Update Firmware OS[cite: 1].
Chain FORWARD Paket melintasi (transiting) router dari interface A ke interface B[cite: 1]. Memblokir akses web client LAN ke situs luar / Internet[cite: 1].
Destination NAT (Dst-NAT) Mengubah IP/Port tujuan sebelum keputusan routing dilakukan[cite: 1]. Port Forwarding ke server lokal di subnet DMZ[cite: 1].

Status Koneksi (Connection Tracking / SPI)[cite: 1]

1. NEW: Paket inisiasi pembukaan koneksi baru[cite: 1].
2. ESTABLISHED: Paket balasan yang tercatat di tabel Conntrack[cite: 1].
3. RELATED: Paket sekunder yang berhubungan (misal FTP Data Channel)[cite: 1].
4. INVALID: Paket liar/rusak yang tidak dikenal statusnya[cite: 1].

Persamaan Translasi Alamat Dst-NAT[cite: 1]

$$\text{Dst-NAT: } (\text{IP}_{\text{Publik}}:80) \longrightarrow (\text{IP}_{\text{DMZ\_Server}}:80)$$ Paket dari WAN menuju IP Publik Router diterjemahkan ke IP Privat Server DMZ secara aman tanpa mengekspos jaringan LAN internal[cite: 1].
