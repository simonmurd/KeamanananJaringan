2 Ringkasan Teori: Virtual Private Network (VPN) & Secure Tunneling

Encryption & Tunneling Protocols

VPN menyedia lorong aman (Encrypted Tunnel) di atas jaringan publik internet yang tidak aman. Dengan enkripsi dan enkapsulasi paket, data yang melintas dilindungi dari penyadapan (Eavesdropping) serta manipulasi pihak ketiga.

Perbandingan Protokol VPN Utama
Protokol VPN Mekanisme Kriptografi / Key Exchange Performa & Overhead Karakteristik Utama
L2TP / IPsec Phase 1 ISAKMP (PSK/Sertifikat) + Phase 2 IPsec ESP Sedang (Overhead ganda L2TP + IPsec) Dukungan bawaan native di hampir seluruh OS desktop & mobile.
OpenVPN TLS/SSL Handshake (OpenSSL / Public Key Infrastructure) Sedang - Berat (User-space processing) Sangat fleksibel, mampu berjalan via TCP/UDP di port 443 (Anti-blocking).
WireGuard Noise Protocol Framework (Pertukaran Public/Private Key) Sangat Tinggi & Ringan (Kernel-level) Kode sangat ringkas (~4000 baris), koneksi instan, tanpa overhead status negotiation.

Arsitektur Site-to-Site VPN

Menghubungkan dua lokasi jaringan lokal utuh (misal Router Kantor Cabang Singkawang dengan Router Kantor Pusat Jakarta) melalui lorong permanen terenkripsi. Seluruh perangkat LAN di kedua sisi saling berkomunikasi transparan tanpa install software client di PC.

Arsitektur Remote Access VPN

Menghubungkan perangkat individu (seperti Laptop Pegawai WFH) langsung ke Gateway VPN kantor. Perangkat pegawai secara virtual dial-up untuk memperoleh Alokasi Virtual IP lokal privat kantor agar bisa mengakses resource internal secara aman.
